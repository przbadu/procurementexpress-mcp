**Step 3: Create src/tools/digital-invoices.ts**

Create new file with `registerDigitalInvoiceTools(server, apiClient)`:

1. **create_digital_invoice** (LOW-06) — Uses `apiClient.postMultipart()`. Accepts:
   - `file_content` (string, required) — Base64-encoded file content
   - `filename` (string, required) — Original filename (e.g., "invoice.pdf")
   - `content_type` (string, optional, default "application/pdf") — MIME type
   - `upload_type` (enum: "invoice" | "request", optional, default "invoice") — "invoice" creates an invoice, "request" creates a PO

Implementation:
```typescript
const fileBuffer = Buffer.from(args.file_content, "base64");
const blob = new Blob([fileBuffer], { type: args.content_type || "application/pdf" });
const form = new FormData();
form.append("file", blob, args.filename);
if (args.upload_type) form.append("upload_type", args.upload_type);
const result = await apiClient.postMultipart(apiClient.buildPath("/digital_invoices"), form);
return jsonResponse(result);
```

Description: "Create an invoice or purchase order from a scanned document. Upload a file (base64-encoded) and the system will process it. upload_type='invoice' (default) creates an invoice, upload_type='request' creates a purchase order."
